# Телеграм-бот для интернет-магазина

Этот проект представляет собой телеграм-бота для интернет-магазина, разработанного с использованием фреймворка `aiogram` (версия 3.14.0) и асинхронной работы с базой данных через `SQLAlchemy`. Бот поддерживает функционал для пользователей и администраторов, включая управление товарами, категориями, корзиной, заказами и баннерами.

## Основные функции

### Для пользователей:
- Просмотр каталога товаров с пагинацией.
- Поиск товаров по ключевым словам.
- Добавление товаров в корзину и управление количеством.
- Оформление заказов.
- Просмотр истории заказов.
- Информация о магазине, оплате и доставке.

### Для администраторов:
- Управление товарами (добавление, редактирование, удаление).
- Управление категориями.
- Загрузка товаров из Excel-файлов.
- Просмотр и обработка заказов (изменение статусов, удаление).
- Управление баннерами (изображения и описания для информационных страниц).
- Просмотр истории удаленных заказов.

## Технологии

- **Язык программирования**: Python
- **Фреймворк для бота**: aiogram 3.14.0
- **База данных**: SQLAlchemy (асинхронная версия)
- **Дополнительные библиотеки**:
  - `aiofiles`, `aiohttp`, `asyncpg`, `pydantic`, `python-dotenv`, `pandas` (для работы с Excel) и другие.
